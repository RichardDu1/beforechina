## 二、 为什么现在的网站「看着有点像 AI 做的」？（真实截图视觉诊断）

我刚才用无头浏览器把首页、医疗页、签证页和手机端全部渲染成高清图片检查了一遍，发现造成「AI 模板感」的核心原因不是代码问题，而是以下 **5 个视觉特征**：

1. **「居中标题 + 居中副标题 + 3/4 等宽卡片 + 线性小图标」循环了 7 次**：
   - 在首页上，从 `Why Travel With Us`（4个线性图标）→ `Healthcare`（3张白卡片）→ `For First-Time Visitors`（3张图）→ `For Nature Lovers`（4张图，第4张还孤零零掉到第二行）→ `For the Adventurous`（3张图）→ `Travel Your Way`（又是5个线性图标）→ `Stories`……
   - **诊断**：真实的人类设计师绝不会在一个页面里用两次「线性小图标 + 居中文字」网格（`WhyUs` 和 `ExperienceGrid` 几乎撞脸），也不会把所有板块都做成一模一样的对称三列。
2. **所有卡片都长得像「SaaS 软件后台」**：
   - 全站的 `.article-card` 都是「白底 + 1px 浅灰边框 + 32px 内边距 + 左边一条 3px 砖红色竖线」。这种样式在工具页出现 1 次很好看，但全站到处都是左边框竖线 + 药丸形小徽章（Pill Badges），就是目前 Claude / GPT 生成网页最典型的「AI 签名特征」。
3. **「温吞的米黄色背景 (`#fdfaf6`) + 砖红色 (`#a84c3a`) + 翠绿色 (`#07C160`)」色彩冲突**：
   - 原本的底色是偏黄的仿古羊皮纸色（想走复古文学风），但工具页和医疗页又用了高饱和度的微信绿 (`#07C160`) 和警告红框。**「复古羊皮纸」撞上「金融计算器绿」**，既不够现代犀利，也不够奢华深邃。
4. **图片复用穿帮**：
   - 首页第一屏大图（故宫铜龟）、`For First-Time Visitors` 的第一张卡片图、以及底部 `Stories from China` 的头条大图，**3 个地方用的是同一张 `golden-triangle.webp` 图片**！一滚屏就露馅了。
5. **字体层级缺乏「编辑部杂志感（Editorial Tension）」**：
   - 现在的字体加载了 `Playfair Display`、`Fraunces`、`Newsreader`、`Inter` 四种字体，但正文中缺乏真正的 **等宽数据字体（Monospace，用于展示价格、汇率、天数、免签小时数）**，也没有明显的「黑白高对比分栏」。

## 三、 改版方案建议：给你 3 个截然不同的「去 AI 味」风格方向

为了彻底甩掉 AI 模板感，我为你设计了 **3 套视觉与布局重构方向**。你可以选一套你最喜欢的（或者混搭），我立即帮你改写全站 CSS 与首页/核心页布局：

### 方向 A：【Monocle / 金融时报周末版（FT Weekend）风格】⭐ 最推荐（兼顾「权威评测 + 高端旅行」）

- **核心气质**：像一本伦敦出版的独立纸质杂志 / 智库报告（参考 _Monocle_, _Financial Times_, * Cereal Magazine*）。
- **色彩系统**：
  - 背景：极干净的 **暖调新闻纸白 (`#F7F5F0`)** 搭配 **深炭墨黑 (`#141413`)** 板块做强烈明暗交替（不再从头到尾一片米白）。
  - 主色：**深朱砂印章红 (`#9E2A2B`)** + **冷松石绿 (`#1B4332`)**（替掉刺眼的亮绿色 `#07C160`）。
- **布局与细节改造（彻底去 AI 味）**：
  1. **干掉圆角阴影卡片与左竖线**：改用 **1px 实线网格（Hairline Editorial Grid）** 和顶部分割线，像报纸版面一样利落。
  2. **引入等宽数字字体 (`JetBrains Mono`)**：所有签证天数（`240 HRS` / `30 DAYS`）、医院价格（`$280 vs $2,400`）、路线天数（`08–10 DAYS`）全部用等宽字体排版，一眼看上去就像严谨的实地调研报告。
  3. **首页砍掉重复的图标区，改为「非对称杂志分栏」**：左侧 40% 是固定标题与导语，右侧 60% 是错落的内容列表；把 `For First-Time / Nature / Adventure` 三个冗长的区块合并为一个带 **Tab 切换（All / First-Time / Nature / Silk Road）** 的精品橱窗，页面长度缩短 40%，精致度翻倍！

---

### 方向 B：【瑞士医疗与极简科技风（One Medical / Stripe Press 风格）】

- **核心气质**：如果你希望把 **「赴华医疗 (`/health`) + 实用行前工具 (`Visa / eSIM / Alipay`)」** 作为绝对主角，这套风格最能建立「安全、现代、透明」的信任感。
- **色彩系统**：
  - 背景：冷调纯白 (`#FAFAFC`) + 浅雾灰 (`#F1F4F9`)。
  - 主色：**深海藏青 (`#0F172A`)** + **瑞士医疗青 (`#0D9488`)** + **点缀朱红 (`#E11D48`)**。
- **布局与细节改造**：
  1. **首屏不再放全屏风景轮播图**：直接把首屏改成 **「左右分栏交互工作台」**——左边是一句话定位 + 3 大核心入口（① 查免签、② 算医疗/看牙省多少钱、③ 选定制路线），右边直接嵌入可交互的快速工具卡片。
  2. **表格与数据卡片极度利落**：像 Apple 官网的参数对比表一样，大量留白 + 超大号无衬线数字。

---

### 方向 C：【东方暗夜奢华风（Aman 安缦 / Songtsam 松赞酒店风格）】

- **核心气质**：纯粹的高客单价私享旅行社调性，静谧、深邃、克制。
- **色彩系统**：
  - 背景：**宣纸米灰 (`#F4F1EA`)** 与 **深竹炭黑 (`#181816`)** 对半交替，搭配 **哑光古铜金 (`#8C6D46`)**。
- **布局与细节改造**：
  1. **大幅留白 + 画廊式图片排版**：一行只放 1~2 张大图，一左一右错落排列（Asymmetric Gallery），配极简的衬线体诗意短句。
  2. **弱化工具感**：把计算器和价格表收敛成极简的折叠抽屉。_(注：这套风格拍风景很好看，但不太适合放看牙、配眼镜和 VPN 价格表。)_
